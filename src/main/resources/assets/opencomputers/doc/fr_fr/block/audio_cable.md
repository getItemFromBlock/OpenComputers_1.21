# Câble audio

![Envoyez le son](oredict:opencomputers:audio_cable)

Les câbles audio transmettent le signal audio des [lecteurs cassettes](tape_drive.md) vers les [haut parleurs](speaker.md). Placez un chemin de câbles afin de connecter un lecteur de cassettes à un ou plusieurs haut parleurs. Quand le lecteur de cassette est en train de jouer, tous les haut parleurs connectés deviennent une sortie audio; si aucun haut parleur n'est connecté, alors le lecteur de cassette utilise son haut parleur interne.

Les câbles audio sont différents des câbles réseau OpenComputers. Ils ne transmettent pas d'énergie et ne connectent pas les périphériques.
