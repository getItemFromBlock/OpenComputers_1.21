# Porte-documents

![Bureaucratie portable.](item:opencomputers:briefcase)

Le porte-documents fournis 18 slots d'inventaire portable.

Prenez-le en tant qu'objet et faites clic droit pour accéder à son contenu. Pour le placer, faites clic droit en étant accroupi. Il peut alors être utilisé comme un petit coffre. Son contenu est préservé quand il est ramassé.

Contrairement au [classeur de documents](filecabinet.md), le porte-documents accepte tout types d'objets.
