# Classeur de documents

![Enfin, un endroit pour mettre toute ma paperasse.](item:opencomputers:filecabinet)

Le classeur de documents fournis 30 slots de stockage pour les documents et autre fournitures de bureau.

Le classeur accepte les [pages imprimées](../item/printedpage.md), les [dossiers](../item/folder.md), le papier, lesl ivres, les livres et plumes ainsi que les livres écrits. Il est possible d'accéder au stockage par le biais d'automatisation comme un coffre vanilla.
