# Boîtier d'ordinateur

![Ah qu'est-ce qu'on est serré...](oredict:opencomputers:case1)

Les boîtiers d'ordinateur existent en 4 tiers différents, ce qui limite les composants qui peuvent y être insérés. Un tier supplémentaire existe aussi, seulement pour le mode créatif. Les boîtiers d'ordinateur peuvent également être placés dans un [assembleur électronique](assembler.md) pour construire des [robots](robot.md).

Le chiffre romain affiché dans le coin d'un emplacement du boîtier indique le tier maximum du composant qui peut y être inséré. Un emplacement de tier 2 peut accepter un composant de tier 1, par exemple.

Le boîtier de tier 1 peut accueillir au maximum les composants suivants :
- 2x cartes d'extension de tier 1 (comme les [cartes graphiques](../item/graphicsCard1.md), les [cartes réseau](../item/lanCard.md), etc.)
- 1x [processeur](../item/cpu1.md) de tier 1
- 2x [barettes de RAM](../item/ram1.md) de tier 1
- 1x [disque dur](../item/hdd1.md) de tier 1

Le boîtier de tier 2 peut accueillir au maximum les composants suivants :
- 1x carte d'extension de tier 2 (comme les [cartes graphiques](../item/graphicsCard1.md), les [cartes réseau](../item/lanCard.md), etc.)
- 1x carte d'extension de tier 1
- 1x [processeur](../item/cpu2.md) de tier 2
- 2x [barettes de RAM](../item/ram3.md) de tier 2
- 1x [disque dur](../item/hdd1.md) de tier 1
- 1x [disque dur](../item/hdd2.md) de tier 2

Le boîtier de tier 3 peut accueillir au maximum les composants suivants :
- 1x carte d'extension de tier 3 (comme les [cartes graphiques](../item/graphicsCard1.md), les [cartes réseau](../item/lanCard.md), etc.)
- 2x carte  d'extension de tier 2
- 1x [processeur](../item/cpu3.md) de tier 3
- 2x [barettes de RAM](../item/ram5.md) de tier 3
- 1x [disque dur](../item/hdd2.md) de tier 2
- 1x [disque dur](../item/hdd3.md) de tier 3
- 1x [disquette](../item/floppy.md)

Le boîtier de tier 4 peut accueillir au maximum les composants suivants :
- 1x carte d'extension de tier 4 (comme les [cartes graphiques](../item/graphicsCard1.md), les [cartes réseau](../item/lanCard.md), etc.)
- 2x carte d'extension de tier 3
- 1x [processeur](../item/cpu3.md) de tier 4
- 2x [barettes de RAM](../item/ram5.md) de tier 4
- 1x [disque dur](../item/hdd2.md) de tier 3
- 1x [disque dur](../item/hdd3.md) de tier 4
- 1x [disquette](../item/floppy.md)

Le boîtier de tier 5 (créatif) peut accueillir les composants suivants :
- 3x carte d'extension de tier 3 (comme les [cartes graphiques](../item/graphicsCard1.md), les [cartes réseau](../item/lanCard.md), etc.)
- 1x [processeur](../item/cpu3.md) de tier 4
- 2x [barettes de RAM](../item/ram5.md) de tier 4
- 2x [disque dur](../item/hdd2.md) de tier 4
- 1x [disquette](../item/floppy.md)
- Il n'a aussi pas besoin d'énergie pour fonctionner.
